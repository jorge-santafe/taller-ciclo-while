# Módulo: Introducción a la Programación

# Sesión: Ciclos Formativos

### Contenido

En este repositorio se encuentra el código fuente de los ejemplos desarrollados durante la sesión Ciclos Formativos, correspondiente al módulo de Introducción a la Programación.

El objetivo es comprender el funcionamiento de los ciclos de repetición, especialmente el ciclo `while`, mediante ejemplos prácticos que faciliten el aprendizaje de las estructuras iterativas en programación.
